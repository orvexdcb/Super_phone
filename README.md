# SUPER PHONE

منصة إعلانات ومتاجر متخصصة بالأجهزة الإلكترونية. هذا المستودع هو نقطة البداية التقنية للمشروع.

## بنية المشروع

- `apps/web`: الموقع الإلكتروني ولوحة الإدارة (Next.js).
- `apps/mobile`: تطبيق Android وiOS (Expo / React Native).
- `packages/shared`: أنواع ومكونات ومنطق مشترك.
- `supabase/migrations`: ملفات ترحيل قاعدة البيانات.
- `docs`: وثائق المتطلبات والقرارات التقنية.

## المتطلبات

- Node.js LTS
- pnpm
- حساب Supabase مستقل لمشروع SUPER PHONE

## التشغيل

```bash
pnpm install
pnpm dev:web
pnpm dev:mobile
```

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local` داخل التطبيق المناسب، وأضف بيانات مشروع Supabase لاحقاً. لا ترفع المفاتيح السرية إلى GitHub.

## قواعد العمل

1. لا تستخدم قاعدة بيانات ORVEX لهذا المشروع.
2. لا تنشئ جداول قبل مراجعة مخطط قاعدة البيانات واعتماد التصميم.
3. جميع صلاحيات الوصول الحساسة يجب فرضها على الخادم وقاعدة البيانات، لا على الواجهة فقط.
4. لا تضع كلمات المرور أو مفاتيح API في المستودع.
