# نطاق المشروع

النسخة الأولى (MVP) تشمل:
- التصفح دون تسجيل.
- التسجيل وتسجيل الدخول.
- نشر إعلانات الأجهزة وصورها ومواصفاتها.
- البحث والتصفية حسب النوع والسعر والحالة والموقع.
- صفحة تفاصيل الإعلان والتواصل المباشر مع البائع.
- المفضلة وإدارة إعلانات المستخدم.
- لوحة مؤسس أولية لإدارة المستخدمين والإعلانات والتصنيفات.

تؤجل المتاجر المتقدمة والمخزون والفروع والتحليلات المتقدمة إلى مراحل لاحقة.

## قواعد أساسية
- المنصة وسيط إعلاني وتقني للتواصل فقط؛ البيع والدفع بين البائع والمشتري والتسليم خارج مسؤولية المنصة ما لم تعتمد خدمة مستقلة لاحقاً.
- التسليم شخصياً فقط في النطاق المعتمد حالياً؛ لا توجد خدمة شحن أو توصيل.
- بيانات SUPER PHONE وقاعدة بياناته مستقلة عن أي مشروع آخر.
